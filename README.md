# Signal Types Classification

Проект посвящен кластеризации сигналов сцинтилляционного детектора на три класса.

В работе выполнены:
- исследовательский анализ данных (EDA);
- извлечение признаков (Feature Engineering);
- сравнение алгоритмов KMeans и Gaussian Mixture Model;
- оценка качества кластеризации;
- интерпретация полученных кластеров.

Лучший результат на Kaggle: 0.43941.
